## 1. Суть проекта
Клиент-only PWA для создания интерактивных досок с упражнениями.
Учитель создает шаблон (доску), раздает ученикам.
Ученики проходят и возвращают прогресс. Никакого бэкенда.

## 2. Железные правила
1. **Никаких платных сервисов и бэкенда.** Только GitHub Pages.
2. **Клиент-only.** Все данные в IndexedDB (Dexie).
3. **Кириллица** — через VS Code или Python/PowerShell (utf-8-sig).
4. **Никаких системных alert/confirm.** Только кастомные Toast/Modal.
5. **Диагностика перед патчем.**

## 3. Окружение и стек
- **Стек:** React 19 + Vite 8 + TypeScript 6 + tldraw 5.6 + Dexie 4.4 + fflate + pdfjs-dist.
- Node: v26.13.0.

## 4. Особенности tldraw v5 и решения
- **Строгая валидация:** Все свойства фигур должны быть в `static override props`. Для опциональных свойств используется `.optional()`. Никаких лишних полей из JSON от ИИ (собираем объекты вручную).
- **Типы vs Значения:** Импорт типов (TLShape, TLResizeInfo) строго через `import type`.
- **Аудио:** Хранится в Dexie (таблица `assets`). `AudioAssetUtil` в tldraw v5 не имеет хука `useAsset`, поэтому файл достается напрямую через Dexie. Для перерисовки плеера используется `key={audioUrl}`.
- **Клики внутри фигур:** Для интерактивных элементов обязателен `onPointerDown={(e) => e.stopPropagation()}`.
- **Авто-высота:** Для всех фигур (MC, FillBlank, RichText, Matching) используется `ResizeObserver` для подстройки высоты под контент.

## 5. Что реализовано
- **Фигуры:** MultipleChoice, FillInTheBlank, Matching (соединение пар), RichText (редактирование на холсте), AudioPlayer (с транскриптом).
- **AI Studio:** Генерация промптов (включая Matching и Rich Text), жесткие JSON-правила из `lucid-mini`, парсинг с авто-чисткой. Шаблоны сохраняют весь план (типы и количество).
- **ZIP:** Экспорт/Импорт шаблона (`board.json` + `assets/`). Экспорт прогресса ученика (`progress.json`).
- **Роли:** Teacher Mode / Student Mode. Античит (в прогресс ученика не попадают правильные ответы).
