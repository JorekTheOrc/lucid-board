## 1. Суть проекта
Клиент-only PWA для создания интерактивных досок с упражнениями.
Учитель создает шаблон (доску), раздает ученикам.
Ученики проходят и возвращают прогресс. Никакого бэкенда.

## 2. Железные правила
1. **Никаких платных сервисов и бэкенда.** Только GitHub Pages.
2. **Клиент-only.** Все данные в IndexedDB (Dexie).
3. **Кириллица** — через VS Code или Python/PowerShell (utf-8-sig).
4. **Никаких системных alert/confirm.** Только кастомные Toast/Modal.
5. **Диагностика перед патчем.**

## 3. Окружение и стек
- **Стек:** React 19 + Vite 8 + TypeScript 6 + tldraw 5.6 + Dexie 4.4 + fflate + pdfjs-dist.
- Node: v26.13.0.

## 4. Особенности tldraw v5 и решения
- **Строгая валидация:** Все свойства фигур должны быть в `static override props`.
- **Типы vs Значения:** Импорт типов (TLShape, TLResizeInfo) строго через `import type`.
- **Аудио и Ассеты:** В tldraw v5 нет встроенного аудио-ассета. Создан `AudioAssetUtil`. Сами файлы хранятся в таблице `assets` в Dexie. Чтобы React пересоздал тег `<audio>`, используется `key={audioUrl}`.
- **Клики внутри фигур:** Для интерактивных элементов (кнопки, ползунки) обязателен `onPointerDown={(e) => e.stopPropagation()}`, иначе холст перехватывает клик.

## 5. Что реализовано
- **Фигуры:** MultipleChoice, FillInTheBlank, RichText (с редактированием прямо на холсте), AudioPlayer (с транскриптом).
- **AI Studio:** Промпт-генератор, парсинг JSON, раскладка по колонкам (текст слева, упражнения справа).
- **ZIP Архивы:** Экспорт/Импорт шаблона (`board.json` + папка `assets/`). Экспорт прогресса ученика (`progress.json`).
- **Роли:** Teacher Mode / Student Mode (с античитом).
