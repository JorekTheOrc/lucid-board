# Lucid Board — Status & Handover

**Обновлено:** 2026-11-10 (MVP-1: ZIP, картинки, PDF, AI, прямое редактирование текста)
**Назначение:** продолжение работы в новой сессии без потери контекста.
**Репозиторий:** https://github.com/JorekTheOrc/lucid-board.git
**Локальный путь:** D:\WEB\lucid-board

## 1. Суть проекта
Клиент-only PWA для создания интерактивных досок с упражнениями.
Учитель создает шаблон (доску с упражнениями), раздает ученикам.
Ученики проходят и возвращают прогресс. Никакого бэкенда.

## 2. Железные правила
1. **Никаких платных сервисов и бэкенда.** Только GitHub Pages.
2. **Клиент-only.** Все данные в IndexedDB и файлах.
3. **Кириллица** — через VS Code или Python/PowerShell (utf-8-sig).
4. **Никаких системных alert/confirm.** Только кастомные Toast/Modal.
5. **Диагностика перед патчем.**

## 3. Окружение и стек
- **Стек:** React 19.3.1 + Vite 8.3.7 + TypeScript 6.0.3 + tldraw 5.6.0 + Dexie 4.4.7 + fflate + pdfjs-dist.
- Node: v26.13.0.

## 4. Архитектура и особенности tldraw v5
- Типы упражнений берутся из `src/types/exercise.ts`.
- tldraw v5 строго валидирует свойства фигур. Если добавляете новое свойство — оно должно быть в `static override props`.
- Read-only режим: `isReadonly: true` (строчная 'd').
- В `RichTextShape` редактирование текста работает прямо на холсте (`contentEditable` по двойному клику). При редактировании текстовое поле не должно перетаскивать холст (используется `onPointerDown={e => e.stopPropagation()}`).

## 5. Что реализовано
### 5.1. Фигуры (Shapes)
- **MultipleChoiceShape**: Мгновенная проверка по кнопке ✓. Есть поддержка нескольких вопросов (вкладки 1, 2, 3 в редакторе).
- **FillInTheBlankShape**: Проверка по Enter или ✓.
- **RichTextShape**: Отображение HTML (Reading, теория). Редактируется прямо на холсте по двойному клику.

### 5.2. Роли и сохранение
- **Teacher Mode / Student Mode**: Переключение скрывает UI, блокирует редактирование и показывает кнопку экспорта прогресса.
- **Экспорт/Импорт ZIP**: Собирает `board.json` и папку `assets/` (картинки) в один архив `fflate`.
- **PDF и Картинки**: Работает загрузка картинок, Drag&Drop/Ctrl+V, и постраничный парсинг PDF (через `pdfjs-dist`).

### 5.3. AI Studio (`AiBuilder.tsx`)
- Генерирует промпт для ИИ (включая Rich Text + вопросы по тексту).
- Поддерживает сохранение шаблонов контекста.
- Раскладывает объекты: текст слева, упражнения справа.
