## 1. Суть проекта
Клиент-only PWA для создания интерактивных досок с упражнениями (для изучения языков).
Учитель создает шаблон (доску с упражнениями, PDF, картинками), раздает ученикам.
Ученики проходят упражнения и возвращают прогресс.
Поддерживается Live-режим (WebRTC P2P 1-на-1) и Async-режим (обмен JSON/ZIP-архивами).
Никакого бэкенда, никаких платных сервисов. Все данные в браузере (IndexedDB).

## 2. Железные правила
1. **Никаких платных сервисов и бэкенда.** Только GitHub Pages / Cloudflare Pages.
2. **Клиент-only.** Все данные в IndexedDB и файлах.
3. **Кириллица** — только через VS Code или Python/PowerShell с UTF-8. PowerShell 5.1 ломает.
4. **Один скрипт — одна правка.**
5. **Диагностика перед патчем.** Сначала смотрим реальный код, потом правим.
6. **Мусор — в .tmp/.**

## 3. Окружение и стек
- **Платформа:** Windows (разработка), Android (использование).
- **Стек:** React 19.3.1 + Vite 8.3.7 + TypeScript 6.0.3 + tldraw 5.6.0 + Dexie 4.4.7 + vite-plugin-pwa 2.0.0.
- **Терминал:** PowerShell 5.1 + Python 3.12.
- Node: v26.13.0 (Current).

## 4. Архитектура данных
- **Типы упражнений** скопированы из проекта `studying-on-android` (`src/types/exercise.ts`). Используются интерфейсы `Exercise`, `Item`, `Option`, `VocabItem`.
- **База данных Dexie** (`src/db/db.ts`): таблицы `boards`, `passes`, `progress`.
- **Сохранение:** Все изменения холста tldraw автоматически (с дебаунсом 800мс) сохраняются в IndexedDB (таблица `boards`).

## 6. Особенности tldraw v5 (Важно!)
- Свойства фигур должны строго соответствовать схеме (`T.object`, `T.arrayOf`). Любое лишнее поле вызовет `ValidationError`.
- Для массива `answer` (строки/булевы значения) нельзя использовать `T.union`, только `T.any`.
- Метод `getIndicatorPath` (возвращает `Path2D`) заменил старый `indicator`.
- Состояние только для чтения: `editor.updateInstanceState({ isReadonly: true })` (строчная `d`!).
- Разрешение кликов в readonly-режиме: `override canEditInReadonly() { return true }`.
